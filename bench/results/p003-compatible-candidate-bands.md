# P003 compatible row-band candidate composition

This offline experiment preserves whole original crop candidates and creates bounded alternatives from complete literal row bands of two independently validated candidates. Nothing is transcribed, corrected, split inside a row, or selected using references. Each generated alternative remains a complete strict table state with `source_conserved=false`; literal strings originated with the two original transcribers.

Before any scoring, the experiment freezes three geometry treatments: exact bbox, IoU>=0.95, and IoU>=0.8. Eligible table pairs require unique one-to-one matching, equal row/column counts, identical literal first-row headers and identical merged-span topology. Tables without a compatible partner remain unchanged from original baseline zero in composites. Ambiguous matching retains only whole original controls. Composite geometry always uses the original baseline-zero bbox; it never averages or invents bounds. Header agreement and equal row indexes do not prove physical row or semantic column alignment, and the artifact explicitly records that limitation.

Vertical merged spans define indivisible row bands: every boundary inside any rowspan is removed before comparing literal values. Each differing band must come wholly from one original candidate. All combinations are enumerated for at most eight differing bands. Larger menus use predeclared all-zero/all-one, every single-band exchange, every prefix split and both parity patterns; this is a bounded source-only pattern family, not a quality-ranked subset or an exhaustive oracle. If the complete pattern family exceeds 256 alternatives, the treatment retains only original whole-crop controls and records capacity refusal. Both original controls are always retained in addition to composite patterns; identical complete state bytes are deduplicated.

`p003_candidate_bands.freeze(viewport,[a,b],threshold=...)` returns a digest-pinned compatibility/band/pattern plan. `alternatives(plan)` reconstructs the frozen plan and returns complete canonical states with exact band provenance. `compose(states,crop_viewports,page_viewport)` validates every whole candidate, preserves all admitted rows/spans, requires complete crop inventory, rejects cross-crop table overlap and enforces the original page slot cap. No invalid original tables are repaired or partially salvaged.

The source-only natural16 pair is P003 Luna1024 plus historical P002 Sonnet1024, authenticated by separate operator-supplied maps and the explicitly root-reviewed historical parser digest. Exactbbox matching yields zero differing compatible bands and retains 35 unique whole-crop controls across 19 crops. IoU 0.95 and 0.8 each admit the same four crops and 11 indivisible differing bands, producing 77 unique crop alternatives. All three treatments are frozen before independent DEV scoring. Six CPU-only tests cover complete row literals, exhaustive small menus, indivisible merged spans, header disagreement, fixed composite geometry, digest tampering, predeclared large menus, capacity refusal, invalid canonical states and atomic cross-crop overlap. Ruff passes.

The runnable offline harness is `p003_candidate_bands_run`, with exactly two repeated explicit `--baseline` / `--trusted-code` arguments, optional root-reviewed parser digest and a fresh `--output`. It preserves a nested source-admission artifact with all original raw reports/requests/errors/costs. Outer `frozen.json` pins every prepared treatment page file, source-admission digest, thresholds, code, records and manifest. All preparation finishes before bounded complete-page feasibility enumeration. There are no model calls or quality references; full pipeline rates are undefined.

Final source-only artifact: `bench/results/pdf-master-artifacts/p003-compatible-bands-v2/`. Per treatment `iou-1.00`, `iou-0.95`, `iou-0.80`, each `{page}-bands.json` contains complete alternatives under `crops[].alternatives[].canonical_json`, original control/band provenance, fixed crop image hash and original geometry. Independent DEV oracle evaluation should authenticate/rebuild these plans before loading references, enumerate the exact frozen alternatives only, and use `compose` to reject invalid full-page combinations. A later paid row-band decision flow is a separate experiment.
