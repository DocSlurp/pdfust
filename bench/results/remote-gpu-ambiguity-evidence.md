# Remote GPU measured ambiguity evidence

The source-only freeze contains 288 inputs per model: all 24 authored DEV regions at fresh RGB edges256 and500, three measured evidence packs (geometry, pixels, both), and two fixed question wordings (original, approved identity). Flash, Clef, PPLX and Intern are predeclared; Qwen9 is an explicitly exploratory generated-choice extension.

The complete fresh504 source matrix was verified before preparation. Measurements use fresh source PDF interpretation and an additional fixed640 pixel probe within the original source crop, irrespective of the model image resolution. This is additional CPU-derived evidence, not an isolated raster-size comparison. The two literal original state/image parts remain unchanged; one separate compact numeric JSON evidence object is appended. Questions retain original or exactly approved identity wording. No extractor semantic choice, scorer references, IDs, source paths or evidence-pack labels enter that supplemental object.

Whitelisted features retain finite numeric values, availability and structural support flags. Inline candidates use axis-aware geometry and transposed pixel scanning with unchanged source footprint. Whitespace, local anchors and color continuity alone establish no semantic row/cell identity. Config, code hashes, full source features and request/image aliases are frozen separately. The reporter recomputes source features and verifies every returned request hash before local DEV scorer access.

Inference and scoring are pending. No improvement is claimed. Every treatment retains24 planned cases (16 known/eight ambiguous), including missing, failed or malformed responses. Native distributions remain separate from stock generated labels with unavailable calibration. Optional matched fresh-original results support paired comparisons; for identity wording, the comparison combines measured evidence and wording changes. Same-prompt prompt-size results are needed to isolate the evidence effect for identity.

Prepare using `python -m bench.remote_ambiguity_evidence prepare --fresh DIRECTORY --output NEW_DIRECTORY`; verify using `verify --packets DIRECTORY`. Report using `report --packets DIRECTORY --run MODEL=RESULT_DIRECTORY` (repeat), optional `--baseline MODEL=FRESH_ORIGINAL_DIRECTORY`, and `--json-output PATH --markdown-output PATH`. Raw source features/provenance remain local artifacts; the worker consumes only its source-only request/image manifest.
