Thus a text-only d1 catalog declaration does not explain this failure. This documentation/catalog conflict prevents treating Luna Decisions as a guaranteed working image control. Regular `openai/gpt-6-luna` is a different language-model route and is not an interchangeable native decision control.

The safe retained HTTP diagnostic has status 400 but no admitted error type or field location. Request-schema rejection, route translation, provider admission, and actual serving-model capability remain possible; the retained evidence cannot distinguish them. HTTP acceptance of the old TypeSafe top-level `images` field is insufficient: its published state contract does not document that image field. [TypeSafe reference](https://vercel.com/docs/ai-gateway/sdks-and-apis/typesafe).
