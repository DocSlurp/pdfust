# P003 complete valid-region candidate admission

This source-only experiment exposes whole valid crop candidates from a failed generation page, while excluding every malformed or overlapping candidate as a complete unit. It never repairs JSON, clamps boxes, salvages individual tables, blends strings or declares a partial page successful. Default candidate runners are unchanged.

`p003_candidate_regions.freeze_page(record,pages,directories,configs,seed=...)` verifies the actual PDF hash, page number/display geometry/rotation, complete source detector proposal order and crop inventory, strict original request bodies, exact original image bytes and image metadata. Historical detector runtime metrics may differ; all detector source evidence must match. A mismatched request, image, source or retained successful crop state is a provenance failure rather than an alternative silently excluded. Complete raw responses are reparsed by the strict transcription adapter and independently checked for viewport containment and intra-crop table overlap. Only parser-invalid or structurally invalid complete states are excluded. Every original generation page/crop, error, call and cost remains in frozen provenance.

Each crop records all attempts, valid origin indexes, exact canonical state bytes/hashes, seed, original image identity and unique valid count. Two or more valid input attempts use the existing randomized opaque candidate pool; its local input indexes map through `valid_baseline_indexes` to actual declared baselines. One unique state is chosen deterministically without a model. An empty valid pool leaves the page uncovered. `compose_selection(frozen, {crop_index:baseline_index})` validates the full frozen digest and selects only exact admitted complete states. Atomic page composition enforces complete crop coverage and page-wide non-overlap. Outputs explicitly retain `source_conserved=false`: their strings were generated by the original transcribers.

The separate `p003_candidate_regions_run` CLI accepts repeated explicit `--baseline` and independent `--trusted-code` maps, plus the existing root-approved historical parser digest only with explicit `--reviewed-parser-sha256`. It authenticates all baselines, freezes every pool before enumeration, copies full original generation reports/requests/code, and records baseline and new code hashes. It then enumerates unique exact candidate compositions, with a fixed16,384 composition cap and no references or quality scoring. Missing requests remain explicit invalid attempts. Rates and hosted costs are undefined; all original generation accounting remains historical provenance.

Fresh Sonnet page `p98d10ef50dee4b24506a` failed atomic composition. Crop0 remains a complete valid candidate; crop1 contains overlapping tables and is excluded entirely. Other baselines provide valid complete alternatives for crop1. The default whole-page candidate-input failure gate suppresses both crop menus on that page; valid-region admission recovers complete selection opportunity for one page without accepting any invalid tables. This is operational opportunity, not a semantic quality improvement. Two successful pages have no detector crops and compose empty output normally.

Five CPU-only tests cover valid responses on failed pages, literal alternative selection, raw failure/cost retention, malformed JSON exclusion, sole-state deterministic choice, uncovered-page refusal, fatal image corruption, whole-candidate overlap exclusion, frozen-pool tampering and atomic cross-crop overlap refusal. Ruff passes. Independent DEV-only oracle quality scoring should consume the frozen pools after this code/admission freeze, without feeding references back into generation/admission.

Ignored source-only artifacts live under `bench/results/pdf-master-artifacts/p003-valid-regions-{pair,triple}-v2/`. They contain immutable `{page}-valid-region-pools.json` files and inventories in `frozen.json`. These are the scorer seam: valid whole states live at `crops[].attempts[].canonical_json`, admitted actual origins at `valid_baseline_indexes`, and original raw crop metadata/response at `attempts[].crop`. Scoring must enumerate only exact admitted canonical states and call atomic `compose_selection`; it must preserve original baseline error/cost reports separately.
