# Lower-level decision experiments: architect proposal

Recommendation: export an opt-in, bounded interpreted-glyph snapshot before `cluster_lines`; evaluate competing local segmentation candidates offline first. Introduce typed model ranking only at ambiguities where correct candidates survive. Do not place a network model inside hayro's callback or replace parsing with generated text.

## Verified evidence boundary

The pinned installed hayro-interpret 0.7.0 `Device` exposes draw_glyph(glyph, transform, glyph_transform, paint, draw_mode), draw_path, draw_image, clip/group callbacks, and begin_marked_content(tag, mcid)/end_marked_content. These are interpreted events, not original operators. OutlineGlyph exposes glyph_id(), font_cache_key(), advance_width(), font_data(), as_unicode(); its original char_code is private. Type3 lacks public glyph-ID/font-key access. Unicode fallback provenance is not exposed, only the selected mapping. Paint distinguishes Color/Pattern; GlyphDrawMode distinguishes Fill/Stroke/Invisible. Fill/stroke PDF text may cause multiple glyph callbacks; callback order does not prove original text-showing operation identity.

Current `rust/src/extract.rs:148` GlyphRecord retains Unicode (possibly a multi-character mapping), origin, approximate size, advance, baseline direction, cached bidi properties, font key/name/flags and accepted-glyph source_order. Source_order counts retained Unicode glyphs, not all operator events. TextCollector ignores paint/mode/marked content and drops unmapped/empty/nonfinite-origin glyphs. Before clustering, writing_mode is always 0; WMode is unavailable and mode-1 is later inferred conservatively.

`collect_page_marks` at extract.rs:5263 returns the original callback-order records. `TextPage::new` at 2179 immediately consumes them through cluster_lines; later order_page_lines and logicalize_rtl_line alter ordering. A snapshot here can preserve evidence that words/dict no longer expose. Glyph bounding boxes currently approximate vertical extents; expose origin/advance/direction truthfully instead of claiming outline or visible-pixel bounds.

Public Page.get_text/Document.get_page_text allow text, words, blocks, dict only. There is no existing rawdict or public glyph API. Dict includes spans/line direction, after clustering and logicalization. Page.get_layout is word/table-based. Reversing these outputs cannot recover text-show boundaries or original glyph memberships.

Marked tags and inline MCIDs are available now, but inspect their limitations: BDC handling extracts MCID from an inline property dictionary; a named property lookup is currently used for optional-content resolution rather than general MCID extraction. Device has no stream/XObject identity, text-show start/end, operator byte offset, raw encoded strings/TJ adjustments, complete text state or ActualText callback. Context state is private. MCIDs without a stream namespace cannot become globally unique source IDs. Marked-content points are ignored. Device visibility is not clip-resolved pixel visibility.

## Smallest bounded hook

Add a private `_Document.extract_glyph_snapshot` one-page API, using existing hayro snapshot acquisition, temporary detachment/restoration and document text/glyph admission. Reinterpret rather than modify/cache TextPage; return owned records and skipped-no-Unicode count. Use a wrapper collector for experimental draw-mode/marked evidence so normal extraction incurs no added fields, collection, network work or branching. Finite glyph/UTF-8 caps constrain the private hook even when compatible DocumentLimits are unbounded; refuse whole output on crossing or allocation failure. No model output edits PDF bytes or populates production caches.

Initial contract: width,height, accepted glyph rows, skipped-no-Unicode count. Rows carry source ordinal, mapping, origin, size, advance, direction, snapshot-local font key/name/flags and draw mode. Font keys identify within interpretation, not stable object IDs. Benchmark harness hashes input and canonical records and pins extension, hayro, fallback-font and schema versions to form snapshot IDs. Later marked-content sidecars should use bounded nesting, bounded tag bytes and all-callback ordinals, preserve malformed nesting diagnostics, and identify stream namespace as unavailable.

Proposed initial caps: 65,536 accepted glyphs; 1 MiB UTF-8 mappings; 256 glyphs per decision window; 256 candidate edges/window; 4 segmentation alternatives plus abstain. Output buffers grow fallibly. Never silently truncate evidence or materialize all-pairs adjacency. Clip/window filtering reduces transmitted evidence, not interpretation work. Existing page admission applies once across text/table/experimental calls and failures do not consume budget.

## Competing experiments

1. **Glyph-window boundary decision (recommended first).** Construct competing local alternatives around ambiguous inline gap/baseline/overprint: same word, boundary, separate paint layer or abstain. Retain both sides' glyph identities, local context and em-normalized geometry. Compare geometry baseline, text/geometry decision model, and geometry-only model using identical candidates. Rank complete alternatives; reject splits inside one multi-character mapping and duplicate/lost glyph ownership. This tests whether model access before WORD_GAP adds anything.
2. **Line/column alternative ranking.** Retain alternate glyph partitions before irreversible baseline clustering or gutter splitting. Small ambiguity windows and complete candidate partitions are essential: independent pair joins can create inconsistent transitive components. Validate exact glyph coverage and acyclic ordering. Compare upstream word-based decisions to this pre-word representation; measure candidate recall separately from ranking.
3. **Marked-content-guided segmentation.** Capture tag/MCID nesting without a hayro fork. Treat tags as producer evidence, not structural truth. Evaluate tagged and untagged cases separately; named-property MCIDs and Form-XObject collisions are explicit missing evidence. This could beat a learned model cheaply, but is a second hook milestone.
4. **Operator-aware parsing trace (defer).** A hayro fork could expose text-show operation boundaries, raw code/Unicode provenance and stream namespace. A lopdf side-parser can inspect operators but matching those operators to hayro glyphs is not guaranteed for forms, encodings, optional content and repeated resources. Measure the minimal glyph experiment before paying this integration cost.

Rejected: hosted call per glyph (latency/cost, huge dependent question graph), generated replacement Unicode (fabricates evidence), feeding entire glyph page without bounded candidates (truncation and quadratic growth), post-hoc rawdict reconstruction (irrecoverable memberships), using glyph outlines/font files in every request (bytes/CPU and no demonstrated need), assuming tagged PDFs have trustworthy reading order, interpreting invisible mode as pixel occlusion, and modifying production cluster thresholds while evaluating model benefit.

## Python verification and evaluation

Use Python tests only. Synthetic raw PDFs from tests/conftest.py build_raw_pdf can pin out-of-order producer drawing, exact and shifted overprint, fill/stroke/invisible text, multi-character ToUnicode, missing Unicode, rotations/CropBox and named versus inline BDC properties. Verify callback-order snapshot differs deliberately from geometric words while original public extraction remains byte-identical; preserve mapping multiplicity. Boundary tests cover finite caps, invalid caps/page, document cumulative limits, repeated calls versus text/table admission, refusal preserving cached extraction, edits invalidating interpretation and immutable returned snapshots surviving close.

Use existing tests/test_overlapping_text.py and tests/test_layout.py as regression suites. Fresh/reused documents need separate CPU wall/time/RSS runs because the private snapshot intentionally reinterprets. Report process scope, environment, one worker, /usr/bin/time -v, and sampling settings. Retain DEV-only PDFs, complete glyph snapshots, candidate alternatives, labels, predictions and invalid/rejected patches in ignored artifacts. No protected held-out-silver access.

Freeze candidate generation, evidence and prompts before a later independent evaluation. Split by PDF producer/document. Measure exact glyph conservation, candidate recall, boundary/partition correctness, accepted error versus coverage, runtime/RSS/serialized bytes and eventual provider usage. Include an oracle over candidates: no ranker can rescue an omitted partition. Compare no-model baseline and post-word pilot on matched cases, including losses and ambiguous/unidentifiable examples. Model confidence remains a ranking statistic until independently calibrated.
