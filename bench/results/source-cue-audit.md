# DEV source cue audit and frozen deletion ablation

The fresh 24-page cohort has a direct answer cue on every page: 16 state “Read each row as one station record.” and eight state “Read each column downward as an independent narrative.” The exact source words enter all 24 retained Luna image512 requests, and the statements also appear in their rendered pixels. This is generator-authored answer guidance, even though private targets were correctly excluded. Existing fresh hosted admission results are cue-contaminated and cannot establish admission quality without those statements. Native geometry candidate ceilings remain diagnostic.

The original 28-page source has neither instruction. “Quarterly observations” and “Review complete” occur on all 28 pages, so they do not reveal class. Its positives use common headers and numeric records; negatives use independent sentence continuations. These are legitimate document semantics, but only six repeated settings and a narrow vocabulary make the synthetic distinction easier than varied producer PDFs. Header presence, row count, font and aligned sentence length may become template shortcuts. The fresh set is similarly narrow: Station/Metric headers, repeated “detail” wraps, literal Total records, and numeric columns. These are not secret labels, but transfer cannot be inferred from this cohort. Fresh request projections include source_words, candidate_tables, geometry, header policy and image mapping; no fresh-* case ID or private target fields enter the projected text. Original source word IDs are snapshot-local wN, not class labels. No heldout or provider responses were read.

`bench/source_cue_audit.py` freezes a new, source-only `explanatory-band-deletion` arm. It blanks only the two exact statements and invariant title/footer strings inside decoded PDF literals. All other decoded operators remain unchanged; compressed streams and cross-reference offsets are regenerated. Every retained word's literal text, bounding box and multiplicity is checked against the original. Original PDFs, references and evidence remain unchanged. Removing bands creates new snapshot-local word IDs; candidate menus must be regenerated rather than reused.

The fresh24 freeze is retained at `bench/results/pdf-master-artifacts/source-neutralized-dev-v1/fresh24/`. Dataset SHA256 is `251253c7a34ae4efcab00b8a4332787d60cda4290350d8ce619ba213ab04d52a`; source evidence SHA256 is `8065e4397e86d84f50c4bdf1abc9f2440c53e2f5a998603dcc90195408e5a00b`. All 24 PDFs and manifest were frozen before extraction; unchanged physical/rolling candidate rules then produced `candidates-frozen.json` and `admission-luna-image512/manifest.json`. `generator-frozen.py` retains the exact preparation source hash; committed generator differences are formatting only. No scoring references were opened and no inference was performed.

Preparation took 0.612 wall seconds and 0.624 process CPU seconds; current executable peak RSS was 105,816,064 bytes, measured by `/proc/self/status` VmHWM without periodic sampling, one sequential CPU process. This covers source extraction/rendering/native candidates; separate candidate/menu freeze resources were not measured. Three focused tests, Ruff and targeted mypy pass, including compressed/uncompressed source handling and metadata invariance.

The paired comparison should retain all 24 pages, identical model/prompt/image512 settings and complete request outcomes/costs. Compare old cue-bearing versus neutral evidence with fresh menus, separating changes in candidate availability from admission decisions. A drop would establish cue dependence, not necessarily poorer document reasoning. After deletion, several authored negatives contain only aligned Station-number fragments and may be genuinely ambiguous; zero-table references remain authored intent, not independently adjudicated truth. Do not optimize prompt wording against those per-case labels. Original28 sentence-continuation controls and independent producer DEV evidence are needed before selecting a deployment rule.
