# Exploratory R002 source-only termination replay

Stopping when every source word is assigned preserves Luna’s five recovered bodies but loses one of PPLX’s six. The three-call cap produces exactly the same stopped states. Both stop before topology edits remain available; neither policy establishes semantic completion. The conservative seen-successor rule never triggers and preserves all original outcomes. These are bounded post-hoc diagnostics, not validated production stopping rules.

The complete family was frozen from all 20 original source traces before derivative target scoring: original behavior, full source ownership, exhausted unseen productive successors, and a three-call cap. Base-audit gold had already been inspected, so this is explicitly exploratory rather than prospective blinded research. No target-based case selection, threshold tuning, source repair or per-case policy choice was used. Every policy retains ten intended sessions per model, nine known content targets and one author-unresolved case. The 80 policy/session observations reuse the same correlated authored regions; they are not independent trials.

## Frozen policies

| Policy | Rule before a next original request | Ending semantics |
|---|---|---|
| Original | Replay the entire retained trace | Preserve original model finish, abstention or loop |
| P1 source complete | Stop when unassigned and deferred inventories are both empty | Controller source-complete action; no model-finish claim |
| P2 seen successors | Require at least one non-finish/non-unresolved proposal, then stop only if every such admissible successor hash was already seen | Controller seen-successors action; empty menus cannot satisfy the rule |
| P3 fixed three | Stop after three original calls; retain any earlier original ending | Controller call-cap action; no completion claim |

Predictions preserve immutable atoms, supplied headers, declared cells and body row coordinates. Policies cannot invent strings, finish operations or geometry. A controller stopping action leaves the source state unchanged and does not set its `finished` flag. Each frozen output retains its state/body hash, original prefix receipt indices, discarded suffix request/receipt identities, exact original cost objects and HTTP times. Targets and literal content comparison reuse the independently reviewed conditional body adapter; supplied headers and neighborhood words earn no content credit.

These are counterfactual suffix omissions over already incurred requests, not realized savings or fresh inference throughput. Realized API savings from this replay are zero. All 83 original calls and costs remain intact: Luna’s 41 zero-reported charges retain their original catalog estimates, while PPLX’s 42 positive provider-reported charges take precedence. A separate receipt check verifies raw provider charges, effective charges and original HTTP times are finite and nonnegative, and preserves all 83 unique receipt identities. Unknown amounts would remain unknown rather than becoming a complete total. The retained evidence does not support promoting source ownership to a semantic stopping criterion. A future prospective study would need a separately frozen source-visible topology qualifier and a new authorized cohort, retaining all policy arms and premature stops. This replay does not select a replacement policy from the target outcomes or launch inference.
