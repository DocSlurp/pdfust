# P003 official Table Transformer postprocessing comparison

The existing geometry controls retained raw model objects but assembled bands and spans with a custom bounded decoder. This experiment compares the published Microsoft Table Transformer postprocessing against exactly the same projected objects and source-owned words. It does not purchase new predictions or change source acquisition. All 16 DEV pages and all nine acquisition-size/threshold combinations are retained before independent scoring.

The official implementation is pinned to commit `16d124f616109746b7785f03085100f1f6247575`, [`src/postprocess.py`](https://github.com/microsoft/table-transformer/blob/16d124f616109746b7785f03085100f1f6247575/src/postprocess.py), SHA256 `a7b3bdf0b0f9ea4b2ccd04bb0acca4bb05b1809d120edf556526a6d976d027db`. Its original MIT license and provenance are retained alongside the ignored source download; execution requires those exact source and license hashes. The repository does not import an unpinned download or install new dependencies.

The treatment uses the same foreground objects at thresholds 0.3 / 0.5 / 0.7 for YOLO acquisition sizes 640 / 1024 / 1280. It supplies only uniquely owned literal source words within the top table object's bounds. Upstream defaults for absent block/line metadata are zero, with original source order as `span_num`. Its row/column refinement uses word containment and resolves header/spanning-cell geometry before assignment. This is a postprocessing comparison, not a reproduction of the entire official model pipeline: the original crop raster, checkpoint, processor size and detector ownership stay as previously frozen.

Returned cells must form a complete rectangular tiling, conserve source IDs and stay within the shared slot limit. Duplicate literals retain distinct IDs. Overlapping tables are all refused; an unexpected upstream error suppresses the entire affected page rather than crediting partial success. The common source-ID materializer produces evaluated cell strings, while original upstream joined strings and structures remain in receipts. Unresolved source words are never discarded.

Six Python tests cover ownership, repeated literal identity, incomplete tiling, overlap refusal, page failure and rejection of altered downloaded code before execution. Ruff passes. Source verification and all output freezing precede independent reference scoring. CPU/RAM resources for postprocessing are measured separately from source authentication and historical detector/structure inference. Results are pending.
