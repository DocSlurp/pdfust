# P003 source geometry and model disputes

The opt-in `--geometry-first --chunked-inventory` treatment first freezes source-only row/column bands, then commits only whole words whose owner has strong support. It uses overlap >=0.98, raw score margin >=0.35, containment after padding by 0.1 median word height, physical-line row gap support, and persistent bilateral whitespace column support. These numbers are deterministic policy parameters, not calibrated probabilities. Native source grids remain protected by the existing runner admission.

An original source-owned table maps only to a unique fixed candidate topology with matching dimensions and merged spans and near-complete original bbox coverage. Unexpressible original tables retain their entire original crop state without requests. Compatible baseline ownership conflicts become model disputes; compatible source ownership is an explicit fallback for model abstention. This preserves complete literal strings and unchanged source ordering inside unchanged cells. It cannot recover missing OCR text.

`p003_topology_hybrid.prepare(snapshot, baseline_tables)` freezes a Hybrid with immutable full source inventory and an admission audit. `batches` emits only disputed word questions (<=16), using chunked target words plus neighboring whole source words and source bands. `collect` strictly reconstructs each exact body and validates typed choices, complete admitted-table row menus, raw probabilities, and the hybrid snapshot digest. `assemble` joins deterministic and model choices atomically; every source ID is owned exactly once. The default two-stage row then anchor protocol remains. Frozen policy and source geometry are regenerated by the independent verifier, not accepted as self-authentication.

The runner stores `{page}-topology-{crop}-hybrid-admission.json`, ordinary row/cell request and response files, row receipt, audit, and updated state. Its frozen config records `geometry_first=true`; it archives the hybrid and geometry helpers. Page failure keeps original Markdown/structure bytes and original baseline provenance, with explicit repair failure. All request accounting remains incremental ownership accounting; full pipeline rates remain undefined.

CPU-only natural16 preflight on the retained OCR300 ordinal source and frozen Luna1024 crops: 11 positive-topology pages prepared, 5 not applicable, no exclusions. Across positive crops, 252 words were committed by geometry, 1,489 were disputed, and two original baseline crops (360 words) were protected because their topology could not be expressed. The two-stage upper bound fell from 280 to 198 requests. Local prepare measured 5.27 s wall, 5.21 s CPU and approximately 347 MB peak RSS. This is preflight coverage and cost opportunity, not measured semantic quality or hosted throughput. No inference or reference scoring was performed.

For an offline probability-blend treatment, the immutable admission supplies `geometry` records keyed by global `source_id` with proposed owner, best score, overlap, margin, source support and baseline agreement. Provider `rows` and `cells` receipts preserve exact asked option probabilities, raw confidence and uncalibrated labels. A blend must retain each exact asked menu; it cannot synthesize cell probability evidence for a row that was not asked in the cell stage. Deterministic locked words have no fabricated probability receipts.

## Single-stage alternative

Add `--ownership-protocol direct_cell` to geometry-first mode to replace row then cell choices with one physical-anchor choice per disputed word. The new pure `p003_topology_direct.batches/collect/assemble` helper retains the same immutable Hybrid and geometry locks. Each menu includes all anchors with positive source-box overlap, the eight highest geometric scores, and the compatible original baseline owner. It explicitly withholds other owners and asks for abstention when the shortlist cannot establish ownership. More than 32 required anchors refuses the complete menu rather than truncating intersecting owners. Every listed anchor carries its source-inferred global bbox, spans, overlap and raw geometric score; these scores are not probabilities.

The exact body contains `ownership_stage=direct_cell`, explicit policy and asked anchor evidence. Decoder receipts contain `hybrid_snapshot_sha256`, `ownership_stage`, and global-source-ID decisions with original provider probabilities. Choice must be a raw maximum from the exact asked menu. Model abstention retains a compatible original baseline owner explicitly; late errors retain the whole original page. Source conservation and literal cell assembly are unchanged. The runner archives the new direct helper, records `ownership_protocol=direct_cell`, uses ordinary row-stem request/response files as the single-stage call list, and additionally writes `{page}-topology-{crop}-direct-receipt.json`. There are no cell-stage requests. The preflight request upper bound is 99 on natural16, compared with 198 for hybrid row then anchor and 280 for all-word row then anchor. This comparison is request opportunity, not semantic quality or paid latency.
