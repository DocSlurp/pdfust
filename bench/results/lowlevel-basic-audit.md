## Findings that change the interpretation

- PPLX crop512: 38/48 known decisions, comprising 24/24 ruled-wrap decisions and 14/24 character-boundary decisions. Crop256 already gives 24/24 ruled-wrap decisions, with 12/24 character boundaries. The extra two answers at 512 px are a small correlated DEV difference, not a resolution requirement. Neither arm abstains on any of the 24 unknowns. The 512 arm therefore makes 10 wrong known assignments plus 24 unsupported assignments among 72 inputs; best known accuracy is not a safe automatic policy.
- d1 canonical: split for all 72 inputs. Its 24/48 known score matches the constant-split baseline, and 24/24 encoding consistency measures constant output. Stability can coexist with complete failure on the join and unknown strata.
- Luna minimal: unresolved on 67/72 inputs. It abstains on all 24 unknowns but also 43/48 answerable inputs. Its five accepted assignments include one wrong known assignment. This does not establish successful calibrated abstention.
- Jev words: 28/48 known, versus 25/48 glyphs and 27/48 operators. Jev resolves all wrap observations as split in these arms, giving 12/24 known wraps and zero unknown abstentions. Its overall gain is in the synthetic boundary-header lane, not recovery of wrapped rows.
- Scalar scores are not independently calibrated correctness; tied maxima abstain mechanically. Exact source ownership proves retained provenance but does not prove semantic grouping. The hardened scorer now derives target relations independently of the candidate aliases and refuses swapped or reordered candidate maps.

The 72 PDFs are 24 related logical templates ×3 encodings; 48 known outcomes are 16 known logical templates, not 48 independent business cases. Crops use authored target selection. Scoring covers two target-text chunks, excluding amount, header-path and complete-cell reconstruction. Handcrafted menu reachability is not automatic candidate recall.

## Source projection review

The current canonical projection removes callback order and downstream native words, whose assembly itself varies with paint order. That is a defensible invariant evidence bundle, but a bundle effect cannot be attributed to callback-order removal alone. Operator projection removes original operator indexes, preventing omitted drawing-operation counts from revealing divider presence. It explicitly disclaims font-decoded Unicode and glyph-to-operator mapping. Neither direct string bytes nor font aliases supply original PDF object provenance.

Minimal is text-only but still includes all page word strings and exact selected chunk text. It can exploit visible header semantics and surrounding document text. Call it a minimal evidence arm, not a context-free or geometry-free reconstruction task. Source-defined chunks/boxes constitute an oracle-selected ambiguity. Identical pixels/source evidence with hidden opposing author intent must remain unknown.

## Critique of the already planned derivative

Resolved/typed/both instructions crossed with minimal, canonical, vectors and resolved crop512 is a reasonable bounded presentation experiment. Preserve source projection and record prompt representation as the treatment; do not make claims about a new model architecture. The source-selected lowest-byte encoding avoids response-based case cherry-picking, but reduces the task to one encoding per logical template. Mark encoding consistency unmeasured/N/A, not zero or perfect. Previously exposed DEV cases remain tuning evidence.

A singleton control should transmit exactly the same per-observation instructions/evidence as the batch arm, changing only packaging. Include all labels and difficult unknowns; do not evaluate only the failures selected after seeing model output. Keep unsupported assignment counts and known-case coverage beside known accuracy, especially for Luna. Treat batches as independent questions with local constraints; answers from the same request are not globally guaranteed consistent.

The decisive next question is whether resolved observed facts recover the frozen geometry answer on model failures. If raw vectors fail while a label-blind description of the same ruling succeeds, that supports evidence translation. It does not establish extra PDF information or surpassing native geometry. A clean translation should state the actually observed divider intersection/outer-cell facts, preserving coordinates/source links and recording the geometric algorithm; it must not emit an authored join/split label disguised as evidence. Compare against code's own deterministic choice.

Freeze the next prompt version before calls and report all arms. A failed follow-up should end this lane or narrow its purpose; it should not trigger indefinite rewriting of synthetic labels. Even a perfect refined prompt on these templates would require independently adjudicated real DEV failures, automatic candidate completeness and held-constant discovery before promotion. Do not access sealed collections during this tuning.

## Performance and practical deployment limits

The retained release study's 2.09× original104 snapshot-plus-text/new-text ratio measures additional interpretation/materialization; it does not show normal-path regression. The hook does not fill the text cache. The standalone CPU reproduction alternates warmed same-build arms, verifies whole-output hashes and mapped-character multiplicity, and retains kernel user/system CPU plus cumulative lifetime RSS. Its same-process RSS cannot establish per-arm memory differences, and its counters include character-conservation checks.

Root's CPython3.14 environment includes all four optional CJK font providers, unlike the stripped CPython3.12 release study. Public automatic fallback setup occurs per fresh Document and belongs in measured work; package versions now appear in the reproduction metadata. Absolute timing ratios from these environments are not directly comparable. A two-repeat smoke is instrument verification only. Input and extension hashes, Python/build provenance, concurrency and warmup protocol must accompany any performance claim.

Before considering model calls per page, prefer deterministic native grouping and a bounded uncertain region menu. Snapshot every glyph only where finer source granularity adds a candidate unavailable in the words arm. The current original104 cost suggests avoiding a second interpretation if a future owned replay path can reconstruct equivalent outputs from one admission, with full Python correctness/resource gates. No model-per-glyph workflow is justified by this evidence.
