# P003 valid-region native selector adapter

The new `p003_candidate_regions_hosted` module makes the frozen valid-region hypothesis runnable by root. It does not modify existing candidate runners or the frozen offline harness. No inference was performed while implementing it.

The adapter first invokes the unchanged offline preparation into `admission/`, finishing independent baseline authentication, whole-crop validity, exact source/request/image matching, immutable complete pools, and bounded atomic composition enumeration. Only then may a root-owned P003 client send native selector questions. Every crop with one unique valid state is deterministic and requires no request. Two or more unique valid states use the existing opaque alias whole-candidate or difference evidence schema. Model selection returns exactly one canonical candidate; strings/topology are never blended. Abstention uses the predeclared lowest valid baseline index for that crop. An invalid first-baseline state can never serve as a crop fallback.

The source-only pair and triple inventories each need 16 native questions across 16 crop viewports (three additional crops have identical/sole states; two pages have no crops). Independent DEV oracle scoring after admission freeze found both pools have the same ceiling: 1088 strict cells and five complete tables. The fresh Sonnet alternative expands operational candidate availability on one previously blocked page but adds no oracle gain to this exact pool. Paid triple selection is therefore not prioritized. These posthoc reference scores are not used in runtime menus, seeds, validity, deterministic fallbacks or prompts.

Root can invoke the adapter with repeated baseline/trust pairs, fresh output, model, `--image-edge`, `--evidence-mode whole|differences`, optional difference cap, seed, optional explicitly reviewed historical parser digest, `--transport-concurrency 1|3`, and mandatory `--run-hosted`. Text-only edge 0 admits the shared decision model allowlist; nonzero images admit only existing image-capable models. Default image rendering and typed parser reuse the existing candidate broker helpers. Shared campaign reservations, deadline, global admission controls and circuit breaker remain in P003DecisionClient/P003ConcurrentClient. All failed requests/reservations remain incremental accounting; historical generation costs are retained separately and require ledger deduplication before any combined total.

Artifact contract for independent verification:

- Outer `frozen.json`: `config.processor=p003_candidate_valid_regions`, complete records/manifest, current code hashes, and `admission={directory:"admission", frozen_sha256, valid_region_pools_sha256}`. Native/helper/concurrent source files are archived under outer `code/`.
- Nested `admission/` is the unchanged offline artifact, including original baseline reports/raw requests/code/cost provenance, source-only immutable pools and complete feasibility report. Independent external baseline trusted-code maps remain required; embedded map values do not authenticate themselves.
- Per page, `{page}-selector-{crop}-request.json` and `-response.json` retain exact native calls. `{page}-result.json` records `ranking_regions`, `ranking_calls`, `ranking_errors`, `original_baseline_status`, `admission_snapshot_sha256` and actual `selected_origins` after success.
- Crop audits retain exact typed model probabilities/raw confidence and map opaque pool input indexes through the frozen `valid_baseline_indexes` to actual original baseline indexes. `deterministic_sole_state` has no fabricated decision receipt. `unresolved_first_valid_fallback` is explicit.
- The verifier rebuilds frozen admission from separately authenticated original inputs, regenerates the exact pool/image/request, strictly parses and selects using the current trusted chooser, then calls `compose_selection(frozen, selected_origins)`. Every crop must be covered; page overlap or any late request/parser/assembly failure restores original first-baseline structure/Markdown bytes and status with `ranking_status=failed_retained_first`. Original generation errors stay copied unchanged. There is no partial-success claim.
- Report `incremental_ranking` includes all selector attempts plus returned call count and resource metrics. Preparation metrics are separately retained from the offline stage. `pages_per_minute` and `pages_per_dollar` are undefined; outputs explicitly remain `source_conserved=false` because their literals came from original transcribers.

Ten tests cover source admission and the paid adapter with isolated fake clients only, including whole-crop rejection, source/provenance corruption, deterministic rescue of an invalid first candidate, typed choice/abstention, malformed-response atomic fallback, original bytes/cost retention, fresh-output refusal, complete 16-page mock execution and concurrent-code freezing. Ruff passes.
