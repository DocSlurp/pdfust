# Genius Inventor proposal: source conservation before more table gates

## Shared decision

Given 125 synthetic DEV pages and 16 OmniDocBench DEV images, choose the next
two experiments that reveal structured extraction failures per dollar in the
remaining roughly 100 minutes. No heldout access, answer leaks, local GPU or
spending beyond the shared $15 cumulative cap.

## Proposal 1: paired evidence sufficiency, then stop paying for easy gates

Freeze D001 geometry, neighbors, blob and hybrid requests before scoring.
Use gate-only questions initially. Choose pages for the first pilot using source
facts only: vector-grid candidates present/absent, geometric fragmentation,
word count and admission status. Retain all-page denominators later. Ask the
same inexpensive provider on paired arms, so disagreement isolates evidence
representation rather than model identity. Reuse already completed equivalent
requests instead of buying duplicates. Do not send refused snapshots.

The interesting outcome is whether geometry plus compact blob preserves the
text/hybrid arm's positive recall while lowering retained tokens and effective
charges. If all cheap arms already agree on easy synthetic tables, terminate
the gate experiment and spend the remaining budget on structure. This corpus's
low positive prevalence makes aggregate accuracy a poor selection objective.

Predeclared pilot: at most 12 source-selected pages, at most three arms, one
provider, no repeated sampling. Root assigns a reservation ceiling before calls;
my proposed ceiling is $1 of remaining budget. Stop if estimated residual spend
crosses that ceiling, provider rejects image input, or 90% of paired answers
agree with no resolved disagreement on vector candidates. Expand only an arm
with a concrete error difference, not a higher confidence number. Report gate
precision/recall/specificity, unresolved counts, actual response tokens, effective
charges, and source-selection rules. No selection claims beyond DEV.

## Proposal 2: bounded wrap/header operations with source-ID conservation

Apply assembly proposals only to source-selected table candidates. Compare
literal-neighbor evidence against the same evidence plus a native source ROI
image; include surrounding notes where source geometry warrants them. Ask
bounded join/separate/unresolved questions and header/other/unresolved role
questions. Preserve complete source inventory through each operation. Reject
answers that invent IDs, reuse a word in two cells, omit owned text or join
fragments across an observed complete divider. This adds deterministic
correctness checks without telling the model which interpretation is correct.

Use four synthetic DEV table pages for counterexample review, then six of the
16 real DEV images with independent annotations used only after requests are
frozen. Image-only pages require actual source OCR or a vision model's retained
word extraction; annotation text must never masquerade as native extraction.
Any real-image experiment must separately report OCR omission/recognition from
cell relation mistakes. If the independent annotation format cannot map source
IDs reliably, report operation validity, coverage and visual review, not
structural accuracy or improvement.

Proposed ceiling: $2 of remaining budget, two arms, one provider. Stop after the
first 12 supported operations or 10 minutes of failing annotation alignment.
Success requires both source conservation and at least two manually documented
cases where one arm fixes a concrete row/header/wrap mistake without introducing
an unsupported merge. A gate win alone is failure of this experiment's purpose.
Freeze evaluation membership before response review and retain failures beside
wins. Do not tune prompt wording case by case after seeing references.

## Considered and rejected

A fifth prompt saying “reason harder” has no isolated mechanism and consumes
budget without improving evidence. An OCR-free raster geometry-only matrix
cannot score ownership when the page text was never extracted. A large
multi-provider table-presence sweep mostly measures easy negative specificity.
Training a cell model now lacks independent source-ID targets and measured
failure volume. A rule-generated candidate is a useful prior, but promoting it
to a gold label would make the experiment circular. Real-page annotation text
as model evidence leaks the answer and is excluded.

## What would change my mind

If retained root results already establish a meaningful disagreement on hard
source regions, skip Proposal 1 and use those paired frozen cases for Proposal
2. If independent cell labels are unavailable within the time box, invest the
second experiment in their offline alignment rather than announcing unmeasured
model extraction gains. The constraint is evidence and validation quality,
not a shortage of creative prompt variants.
